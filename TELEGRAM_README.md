# Telegram Integration Guide

This guide explains how to set up and use the Telegram bot integration to automatically post trending keywords to a Telegram channel.

## Prerequisites

1. Create a Telegram Bot:
   - Open Telegram and search for @BotFather
   - Send `/newbot` command
   - Follow the prompts to create your bot
   - Save the bot token (looks like: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

2. Create or use an existing Telegram Channel:
   - Create a new channel in Telegram (or use existing)
   - Add your bot as an administrator to the channel
   - Get the channel ID (see below)

3. Get Channel ID:
   - Option 1: If your channel is public, use `@channelname`
   - Option 2: For private channels:
     - Add your bot to the channel as admin
     - Send a message to the channel
     - Visit: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
     - Look for the channel ID in the response (usually negative number like `-1001234567890`)

## Configuration

### 1. Environment Variables

Add these to your `.env` file:

```env
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_CHANNEL_ID=@your_channel_id_or_numeric_id
```

### 2. Install Dependencies

The required dependency is already in requirements.txt:
```bash
pip install python-telegram-bot>=21.0
```

## Usage

### Manual Posting via API

You can manually trigger a post to Telegram using the API endpoint:

```bash
# Post latest trending keywords from database
curl -X POST http://localhost:5003/telegram/post \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "use_latest": true,
    "root_user_id": "optional_user_id"
  }'

# Post custom trending data
curl -X POST http://localhost:5003/telegram/post \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "use_latest": false,
    "trending_data": {
      "trending_keywords": [
        {"keyword": "AI", "frequency": 0.85, "type": "single"},
        {"keyword": "machine learning", "frequency": 0.72, "type": "phrase"}
      ],
      "root_user_id": "elonmusk",
      "topics": {
        "trending_topics": [
          {
            "topic_name": "Technology",
            "keywords": ["AI", "ML", "automation"]
          }
        ]
      }
    }
  }'
```

### Automatic Posting with Scheduler

To enable automatic Telegram posting after scheduled analysis:

1. Add a user with Telegram enabled:
```bash
curl -X POST http://localhost:5003/scheduler/users \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "elonmusk",
    "telegram_config": {
      "enabled": true,
      "post_after_analysis": true
    }
  }'
```

2. Update existing user to enable Telegram:
```bash
curl -X PUT http://localhost:5003/scheduler/users/elonmusk \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "telegram_config": {
      "enabled": true,
      "post_after_analysis": true
    }
  }'
```

## Troubleshooting

### Bot Token Issues
- Ensure the token is correct and the bot is active
- Test the bot by sending `/start` command directly to the bot

### Channel ID Issues
- Make sure the bot is an administrator in the channel
- For private channels, ensure you're using the numeric ID (with minus sign)
- Test by sending a message manually using the Telegram Bot API

### Permission Errors
- Check that the bot has permission to post messages in the channel
- Ensure the bot is added as an administrator, not just a member

### Message Formatting
- The service uses Markdown formatting
- Special characters in keywords may need escaping

## Security Notes

- Never commit your bot token to version control
- Keep your `.env` file secure and private
- Consider using different bots for development and production
- Regularly rotate your bot tokens if needed
